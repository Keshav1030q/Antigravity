# 🚀 Antigravity Learning Playground

A responsive, interactive sandbox website built to test and learn web development and deployment pipelines.

## 🌟 Features
- **Zero-Gravity Touch & Particle Physics**: Interactive floating canvas particles that react to mouse and touch on mobile devices.
- **Live System Clock**: Dynamic time, date, and greeting calculation.
- **Client-Side Persistence (LocalStorage)**: An idea scratchpad where notes stay saved even when refreshing the page.
- **Modern Glassmorphic Design**: Fully responsive layout tailored for mobile phones, tablets, and desktop displays.

## 🛠️ Tech Stack
- **HTML5**: Page structure and semantic layout.
- **CSS3**: Custom styles, responsive grid, glassmorphism backdrop filters, and animations.
- **JavaScript (ES6+)**: Canvas animation loop, DOM manipulation, touch events, and browser storage.
- **Hosting**: GitHub Pages.
